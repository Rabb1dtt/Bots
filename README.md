# EA FC 26 Career Master Bot

Телеграм-бот, который выступает гейммастером для карьеры тренера в EA FC 26. Первая итерация фокусируется на подборе клубов и выдаче оффера.

## Возможности
- /start отправляет описание бота и кнопку **<Создать тренера>**.
- Пошаговый сбор анкеты тренера: национальность через кнопки с флагами + "Другая" с текстовым вводом, пол, возрастные диапазоны, футбольное прошлое, лицензия, краткая биография.
- Анализ анкеты и подбор 5 клубов из разных лиг с процентами шансов оффера.
- Кнопка **<Получить оффер>** запускает сценарий переговоров (агент обзванивает клубы) и выдает финальный клуб.
- Кнопка **<Подписать контракт>** закрепляет выбор и позволяет начать заново.

## LLM интеграция (опционально)
Сейчас подбор офферов делает локальная эвристика, но в `src/bot.js` есть точка расширения `buildOffers`, куда можно подключить LLM (например OpenAI, Azure OpenAI, Gemini, Claude и т.п.).

Минимально нужно:
- API ключ провайдера, клиент для запросов и обработка ответа.
- Промпт, который получает профиль тренера + список лиг/клубов и возвращает 5 клубов из 5 разных лиг с вероятностями.
- В окружении: `OPENAI_API_KEY` (ключ API), опционально `OPENAI_MODEL` (по умолчанию `gpt-5.2-mini`).

Пример идеи промпта:
```
Ты футбольный ассистент. Используй только клубы из списка.
Профиль тренера: {profile}
Список лиг и клубов (JSON): {leagues}
Задача: выбери 5 клубов из 5 разных лиг, верни JSON:
[{league, club, probability, reason}], вероятность суммарно 100.
```

Где хранить лиги/клубы:
1) Локальный JSON (рекомендуется) — `src/data/leagues.json`. LLM получает этот список и выбирает только из него.
2) Внешний источник — например Google Sheets с лигами/клубами. Можно читать таблицу через Sheets API и либо отдавать данные в LLM, либо синхронизировать в JSON.
3) Автопоиск в сети — LLM сам ищет клубы по лигам, но важно затем валидировать список на соответствие EA FC 26.

## Запуск
1. Скопируйте пример env:
   ```bash
   cp .env.example .env
   ```
2. В файле `.env` укажите `BOT_TOKEN` вашего Telegram-бота.
3. Установите зависимости и запустите бота:
   ```bash
   npm install
   npm start
   ```

Бот хранит прогресс в памяти процесса, поэтому для каждого пользователя анкета изолирована, но после перезапуска потребуется заполнить заново.
